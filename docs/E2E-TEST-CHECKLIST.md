# 2circle — E2E Test Checklist (User Acceptance Testing)

> Инструкция для тестировщика: пройдите каждый сценарий от начала до конца.
> Отмечайте OK / BUG. При баге — фиксируйте: экран, действие, ожидание, реальность.

---

## Подготовка

- [ ] Установить APK на реальный телефон
- [ ] Убедиться, что телефон и компьютер в одной WiFi сети
- [ ] Сервер запущен (serve.py на 192.168.1.42:8765)

---

## Сценарий 1: Первый запуск (Onboarding + Splash)

- [ ] Удалить приложение (полное удаление)
- [ ] Установить APK
- [ ] Запустить → **Splash screen** с анимацией двух кругов + слоган
- [ ] Переход к **Onboarding** — 3 карточки
- [ ] Листать: карточка 1 (карты), карточка 2 (поиск), карточка 3 (запись)
- [ ] Нажать **"Skip"** или **"Начать"** → переход на карту
- [ ] Отметить: показался ли splash? анимация плавная? onboarding на русском?

---

## Сценарий 2: Скачивание региона

- [ ] Перейти во вкладку **Регионы**
- [ ] Нажать **Обновить** → должен появиться список (Andorra, Central Russia, Ural)
- [ ] Нажать **Скачать** на Andorra (быстро, 2.5 MB)
- [ ] Дождаться: прогресс-бар → "Проверка…" → "Распаковка…" → "Удалить" (установлено)
- [ ] Нажать **Скачать** на Ural (733 MB) — проверить что докачка работает
- [ ] Если прервать и возобновить → должна продолжиться с места обрыва
- [ ] Проверить бейдж **"✓ Активный"** на скачанном регионе
- [ ] Нажать на другой установленный регион → radio-button переключает активный

---

## Сценарий 3: Карта — навигация и взаимодействие

- [ ] Открыть вкладку **Карта**
- [ ] Карта отрисована (не чёрная), видны дороги, надписи, вода
- [ ] **Свайп** влево/вправо/вверх/вниз → карта двигается
- [ ] **Pinch zoom** (два пальца) → масштаб меняется
- [ ] **Double-tap** → зум увеличивается
- [ ] **Вращение** двумя пальцами → карта вращается, компас в top-bar поворачивается
- [ ] Нажать на **компас** → карта возвращается север-вверх
- [ ] Внизу-слева виден **масштаб** ("1 км" и т.д.)
- [ ] При зуме ≥14 видны **названия улиц**

---

## Сценарий 4: POI — точки интереса

- [ ] На карте нажать **чипс категорий** внизу (или FAB POI)
- [ ] Выбрать **Аптека** → маркеры появляются на карте
- [ ] Нажать на **маркер** аптеки → открывается карточка с именем, категорией, координатами
- [ ] Нажать **"В маршрут"** → карточка закрывается, появляется уведомление
- [ ] Выбрать **Кафе** → маркеры обновляются
- [ ] Снять выбор (тап по активному чипу) → маркеры исчезают
- [ ] Выбрать несколько категорий одновременно → все маркеры видны

---

## Сценарий 5: Поиск места

- [ ] Нажать **иконку поиска** (лупа) в top-bar карты
- [ ] Ввести "Andorra" → результаты появляются
- [ ] Проверить: имя, тип (город/деревня), расстояние, население
- [ ] Нажать на результат → карта **перемещается** к этому месту
- [ ] Вернуться в поиск → ввести "Escaldes" → найти
- [ ] Нажать **"В маршрут"** → точка добавлена, остаётесь в поиске
- [ ] Вернуться на карту (Back)

---

## Сценарий 6: Построение маршрута

- [ ] Открыть вкладку **Маршруты**
- [ ] Проверить: точки из поиска (Andorra + Escaldes) видны в списке
- [ ] Выбрать профиль: **Туринг** / **Шоссе** / **МТБ**
- [ ] Нажать **"Построить маршрут"**
- [ ] Дождаться: "Прокладка…" → результат (дистанция, время, набор, спуск)
- [ ] Проверить **диаграмму покрытий** (полоска: % асфальт/гравий/грунт)
- [ ] Проверить **график высот** (кривая с заливкой)
- [ ] Нажать **"Сохранить маршрут"** → должно сохраниться
- [ ] Нажать **"Сохранённые маршруты"** → сохранённый маршрут в списке
- [ ] Нажать на сохранённый → загружается в Route Builder
- [ ] Удалить точку (кнопка ×) → список обновляется
- [ **Drag-to-reorder:** зажать ⠿ на точке → перетащить → порядок меняется
- [ ] Проверить: если удалить все точки → empty state с подсказкой

---

## Сценарий 7: Долгое нажатие на карте

- [ ] На карте — **долгое нажатие** в произвольной точке
- [ ] Точка добавляется в маршрут (уведомление/Snackbar)
- [ ] Перейти в Маршруты → точка видна (Manual, координаты)
- [ ] Долгое нажатие в другом месте → добавляется ещё точка
- [ ] Предыдущая точка **не пропадает** (проверка RouteDraftRepository)

---

## Сценарий 8: Запись поездки (Tracking)

- [ ] На карте нажать **кнопку записи** (▶ в FabCluster или tracking screen)
- [ ] Появляется **уведомление** в шторке ("2circle — запись")
- [ ] На экране Поездка: дистанция, скорость, время, набор высоты
- [ ] Пройти/проехать немного (или сэмулировать движение)
- [ ] Проверить: данные обновляются в реальном времени
- [ ] Нажать **Стоп** → запись завершена
- [ ] Перейти в **Треки** → новый трек в списке

---

## Сценарий 9: Просмотр и экспорт трека

- [ ] В Треках нажать на трек → **детали**
- [ ] Проверить: мини-карта с полилинией, StatGrid (2×3), график высот
- [ ] Нажать **"Экспорт GPX"** → системный share sheet открывается
- [ ] Сохранить GPX файл
- [ ] Нажать **"Удалить"** → диалог подтверждения → подтвердить → трек удалён
- [ ] Проверить: трека больше нет в списке

---

## Сценарий 10: Импорт GPX

- [ ] В Треках нажать **"Импорт GPX"**
- [ ] Системный picker файлов открывается
- [ ] Выбрать .gpx файл (из ранее экспортированного)
- [ ] Дождаться импорта → трек появляется в списке
- [ ] Открыть импортированный трек → данные корректны

---

## Сценарий 11: Регистрация и вход

- [ ] Перейти во вкладку **Профиль** → виден гостевой режим ("Войдите в 2circle")
- [ ] Нажать **Войти** → экран Login
- [ ] Ввести некорректный email → ошибка валидации
- [ ] Ввести корректный email + короткий пароль → ошибка "минимум 8 символов"
- [ ] Ввести корректные данные → нажать **Войти** → спиннер → вход выполнен
- [ ] Профиль обновился: имя, аватар, статистика
- [ ] Нажать **Выйти** → возврат в гостевой режим
- [ ] Перейти на **Регистрацию** → заполнить все поля → создать аккаунт → профиль обновлён
- [ ] Проверить: чекбокс "условия" без галочки → кнопка блокируется

---

## Сценарий 12: Лента сообщества

- [ ] Перейти во вкладку **Лента**
- [ ] Видны карточки поездок (mock-данные)
- [ ] Проверить: мини-карта, имя автора, название поездки, статистика
- [ ] Нажать **❤️ (kudos)** → анимация heart burst + виброотклик + счётчик увеличивается
- [ ] Нажать ещё раз → kudos снимается
- [ ] **Pull-to-refresh** → потянуть вниз → индикатор обновления

## Сценарий 16: Офлайн-режим

- [ ] Включить **Airplane mode** на телефоне
- [ ] Открыть карту → карта работает (оффлайн тайлы)
- [ ] Поиск → работает (оффлайн search.db)
- [ ] POI → работают (оффлайн search.db)
- [ ] Надписи на карте видны (шрифты встроены в APK)
- [ ] Построение маршрута → работает (оффлайн BRouter, если rd5 есть)
- [ ] Запись трека → работает (GPS не требует интернета)

## Сценарий 17: Skeleton loaders и анимации

- [ ] В Ленте → потянуть refresh → видны **shimmer-плейсхолдеры** при загрузке
- [ ] В Треках → shimmer при загрузке списка
- [ ] Переход между вкладками → **плавный fade** (150ms)
- [ ] Переход из поиска в карту → **slide** анимация
- [ ] FAB cluster → **каскадное раскрытие** (задержка между кнопками)

---

## Сценарий 18: Ошибки и edge cases

- [ ] Удалить все регионы → карта: "Нет оффлайн региона"
- [ ] Поиск без региона → "Скачайте регион для поиска"
- [ ] Маршрут без точек → empty state
- [ ] Маршрут с 1 точкой → "Добавьте ещё одну точку"
- [ ] Нет GPS → кнопка записи/навигации → graceful handling
- [ ] Нет интернета + нет региона → все fallback сообщения корректны
