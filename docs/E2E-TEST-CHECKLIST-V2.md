# 2circle — E2E Test Checklist v2 (Дополнительные сценарии)

> Дополнение к основному чек-листу. 8 сценариев, выявленных при аудите покрытия.

---

## Сценарий 19: Переключение активного региона

- [ ] Скачать **2 региона** (например Andorra + Ural)
- [ ] Активный = Andorra → открыть карту → видна Андорра
- [ ] Перейти в Регионы → нажать radio на **Ural** → "✓ Активный"
- [ ] Вернуться на карту → **карта должна переключиться на Урал**
- [ ] Открыть поиск → ввести "Челябинск" → **должен найтись** (search.db Урала)
- [ ] Ввести "Andorra" → **не должен найтись** (search.db Андорры не активен)
- [ ] Вернуться в Регионы → переключить обратно на Andorra → карта возвращается
- [ ] Удалить **активный** регион → карта: "Нет оффлайн региона"
- [ ] Если установлен другой регион → он должен стать активным автоматически

**Критично:** карта ДОЛЖНА меняться при переключении. Если нет — баг.

---

## Сценарий 20: Живая полилиния трека на карте

- [ ] Открыть карту
- [ ] Начать запись трека
- [ ] Пройти/проехать ~50 метров
- [ ] **На карте должна появиться зелёная линия** — записанный путь
- [ ] Линия должна **удлиняться** по мере движения
- [ ] Остановить запись
- [ ] Линия должна остаться на карте (или исчезнуть — оба варианта допустимы)

**Критично:** если полилиния не появляется во время записи — TrackOverlayLayer не работает.

---

## Сценарий 21: Пауза и возобновление записи

- [ ] Начать запись трека
- [ ] Пройти немного → дистанция увеличивается
- [ ] Нажать **Пауза** → запись должна остановиться
- [ ] Подождать 30 секунд → дистанция **не должна** увеличиться
- [ ] Нажать **Возобновить** → запись продолжается
- [ ] Пройти ещё → дистанция снова увеличивается
- [ ] Остановить → трек сохраняется с правильной длительностью

**Критично:** пауза не должна учитываться как время движения.

---

## Сценарий 22: My-location FAB и follow mode

- [ ] Открыть карту
- [ ] Нажать иконку **геолокации** (мишень, внизу-слева)
- [ ] Карта должна **переместиться к вашей позиции** (если GPS разрешён)
- [ ] Иконка меняет цвет/вид → активен **follow mode**
- [ ] Свайпнуть карту вручную → follow mode **отключается**
- [ ] Нажать ещё раз → снова follow mode

**Если GPS не работает:** проверить что есть graceful fallback (не краш).

---

## Сценарий 23: POI → "В маршрут" → реальное добавление

- [ ] Открыть POI категории → выбрать Аптека
- [ ] Тап по маркеру → карточка POI
- [ ] Нажать **"В маршрут"**
- [ ] Перейти во вкладку **Маршруты**
- [ ] **Точка должна быть в списке** с именем POI (например "Farmàcia Rocamora")
- [ ] Source должен быть **Search** (не Manual)
- [ ] Добавить ещё одну точку (другой способ)
- [ ] Обе точки должны сохраниться

---

## Сценарий 24: Logout и повторный вход

- [ ] Войти в аккаунт (mock)
- [ ] Проверить: профиль показывает имя пользователя
- [ ] Нажать **Выйти**
- [ ] Профиль → **гостевой режим** ("Войдите в 2circle")
- [ ] Закрыть приложение полностью (смахнуть из рекents)
- [ ] Открыть снова → профиль всё ещё **гостевой** (не автологин)
- [ ] Войти снова → работает

---

## Сценарий 25: Hardware Back button

- [ ] На карте → нажать Back → **не должен выходить из приложения** (или подтвердить выход)
- [ ] В поиске → Back → возврат на карту
- [ ] В деталях трека → Back → возврат в список треков
- [ ] В настройках → Back → возврат на предыдущий экран
- [ ] В Route Builder → Back → возврат на карту
- [ ] В Saved Routes → Back → возврат в Route Builder
- [ ] При открытой bottom sheet (POI) → Back → sheet закрывается (не выход)

---

## Сценарий 26: Уведомление о записи трека

- [ ] Начать запись трека
- [ ] Свернуть приложение (Home button)
- [ ] Открыть шторку уведомлений → **видно "2circle — запись"**
- [ ] Тап по уведомлению → **приложение открывается** на экране записи
- [ ] Уведомление содержит текущую дистанцию/время
- [ ] Остановить запись → **уведомление исчезает**
- [ ] Если убить приложение (force stop) → при перезапуске предложить восстановить прерванный трек
